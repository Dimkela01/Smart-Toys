# Content: activities, lessons, stories, characters

Principle: **the LLM is the voice and personality; code is the teacher.** The activity engine
decides what happens next and whether an answer is correct. The LLM only phrases the step in
Bruno's voice, using the `ACTIVITY` block.

Target ages for MVP content: 4–8 (works for 3–10 with simpler/harder levels).

## 1. Activities

| ID | Activity | Card icon | Engine | LLM role |
|---|---|---|---|---|
| `why` | "Why?" free questions | question mark | none (free conversation) | answers within system prompt rules |
| `story` | Choose-your-story | open book | story engine with state | tells each part, offers 2 choices |
| `numbers` | Numbers game | apples | lesson engine, deterministic checking | phrases exercise, praise, hints |
| `english` | English words | ABC | lesson engine, fuzzy matching | phrases prompts and praise |

Default when the child just talks without choosing: `why`.

## 2. "Why?" questions

- No activity block; the system prompt and memory apply.
- Topic tags for summaries come from a fixed list: animals, nature, space, weather, body-basic (allowed: e.g. why we sleep), vehicles, how-things-work, food, music, sport, feelings-light, other.
- Suggested follow-up: after 3 free turns, Bruno may offer an activity ("Hoćeš da se igramo brojeva?").

## 3. Lesson format (numbers, English)

Lessons are JSON files in `content/lessons/`. Exercises are generated by code from templates.

```json
{
  "id": "numbers.add_to_10",
  "activity": "numbers",
  "title": {"sr": "Sabiranje do 10", "en": "Adding up to 10"},
  "age_range": [5, 7],
  "levels": [
    {"level": 1, "generator": "count_objects", "params": {"min": 1, "max": 5}},
    {"level": 2, "generator": "add", "params": {"a": [1, 5], "b": [1, 4], "max_sum": 6}},
    {"level": 3, "generator": "add", "params": {"a": [1, 9], "b": [1, 9], "max_sum": 10}},
    {"level": 4, "generator": "subtract", "params": {"a": [3, 10], "b": [1, 5], "min_result": 0}}
  ],
  "objects": ["apples", "stars", "cars", "balloons"],
  "exercises_per_round": 5,
  "level_up_if_correct": 4,
  "hints": {
    "sr": ["Pokušaj da prebrojiš prstima.", "Kreni od {a} i dodaj još {b}."],
    "en": ["Try counting on your fingers.", "Start at {a} and add {b} more."]
  }
}
```

### 3.1 Lesson engine state

```json
{
  "lesson_id": "numbers.add_to_10",
  "level": 2,
  "round_index": 3,
  "exercise": {"type": "add", "a": 3, "b": 2, "answer": 5, "object": "apples"},
  "attempts": 1,
  "correct_in_round": 2
}
```

### 3.2 Turn logic
1. Parse the child's answer: number words SR (`nula`…`dvadeset`, including colloquial forms like `pet`, `petica`), EN (`zero`…`twenty`), digits. English activity: normalize and compare with accepted forms (Levenshtein ≤ 1 for words ≥ 4 letters).
2. Decide: `correct` / `wrong` / `no_answer` (child said something else) / `stop` (child wants to quit).
3. Build the `ACTIVITY` block with the decision and the next step, e.g.
   `AKTIVNOST: brojevi, nivo 2. Zadatak je bio 3 + 2. Dete je reklo 4: NETAČNO, prvi pokušaj. Daj nagoveštaj: "Kreni od 3 i dodaj još 2." Ne reci tačan odgovor.`
4. Send the `visual` event (pictures of objects) to the client.
5. After the round: praise + level change saved as bookmark `numbers_level`.

The LLM is explicitly told not to solve the exercise or judge correctness; the output filter
rejects a sentence containing the answer when the engine said "don't reveal" (simple check for the number).

### 3.3 English word lists
`content/english/{theme}.json` with items: `{"en": "red", "sr": "crvena", "image": "colors/red.webp", "accept": ["red", "rad"]}`.
Themes for MVP: colors, animals, numbers 1–10, family, food, body-basic (head, hand, nose…). Max 5 new words per session; review 2 learned words at the start.

## 4. Story format

Stories are generated live from a **story seed** plus state, in 4–6 parts.

Seed files `content/stories/seeds.json`:

```json
{
  "id": "lost_star",
  "title": {"sr": "Zvezda koja se izgubila", "en": "The Lost Star"},
  "hero_options": ["zeka", "meda", "mali zmaj"],
  "place_options": ["šuma", "more", "oblaci"],
  "problem": {"sr": "Mala zvezda je pala sa neba i ne zna kako da se vrati.", "en": "A little star fell from the sky and doesn't know how to get back."},
  "values": ["helping", "friendship"],
  "parts": 5
}
```

Story state:

```json
{
  "seed_id": "lost_star",
  "hero": "zeka",
  "place": "šuma",
  "part": 3,
  "facts": ["Zeka se zove Cica", "Sova je obećala da pomogne"],
  "last_choice": "otići do velikog drveta",
  "next_choices": ["pitati sovu", "popeti se na brdo"]
}
```

Rules:
- Each part: 3–4 sentences, then two choices (shown also as two pictures).
- The engine updates `facts` after each part using a constrained JSON call (grammar/JSON schema) with max 3 new facts; facts must not include personal data.
- Gentle content only: no villains that hurt, no scary endings; problems are solved by kindness, cleverness or teamwork.
- During allowed-hours' last 60 minutes, stories end calmly ("i svi su slatko zaspali").
- At the end: suggestion to tell the story to a parent; bookmark cleared.
- Unfinished story → `story_bookmark` → next session Bruno offers to continue.

## 5. Characters

`content/characters/{id}.json`:

```json
{
  "id": "bruno_bear",
  "name": {"sr": "Bruno", "en": "Bruno"},
  "species": "bear",
  "personality": {
    "sr": "Bruno je nežan, radoznao meda koji voli prirodu i med.",
    "en": "Bruno is a gentle, curious bear who loves nature and honey."
  },
  "voice": {"sr": "piper:sr_voice_id", "en": "kokoro:af_heart"},
  "animation": "characters/bruno_bear.riv",
  "greetings": {"sr": ["Zdravo, {name}!"], "en": ["Hi, {name}!"]}
}
```

MVP characters: `bruno_bear`, `zeka_bunny`, `robi_robot`. Changing a character requires no code change
(white-label demo for toy companies).

## 6. Intent detection

Order: card tap (explicit) → keyword rules → fallback `why`.

| Intent | SR keywords (normalized) | EN keywords |
|---|---|---|
| `story` | prica, price, ispricaj, bajka | story, tell me a story, fairy tale |
| `numbers` | brojevi, brojimo, racunamo, matematika, sabiranje | numbers, counting, math, adding |
| `english` | engleski, kako se kaze na engleskom | english, words, how do you say |
| `stop_activity` | dosta, necu vise, hocu nesto drugo, kraj | stop, enough, something else |
| `continue_story` | nastavi, dalje, sta je bilo | continue, what happened next |

Keyword lists live in `content/intents/{sr,en}.yaml`. Disabled activities are never started; Bruno declines kindly.

## 7. Content not in MVP

Reading and letters (need visual curriculum), emotional coaching or "talk about feelings" sessions
(wait for CRIA), news, history, religion, science experiments with materials.
All new content is reviewed by an educator before going live.
